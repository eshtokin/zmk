# Toki Split 1 layers

Source: `config/toki_split1.keymap`

Format: each layer shows the main 3x10 key area. Empty positions are left blank.

## Base

```text
Q W E R T   Y U I O P
A S D F G   H J K L ;
Z X C V B   N M , . /
```

Outer keys:

```text
Tab                 \
Ctrl                '
Shift               Shift
```

Thumbs:

```text
Alt GUI/Mouse Ctrl/Esc Space Enter   Backspace Space GUI RAlt Util
```

## Q -> Short

```text
              Cmd+[       Cmd+]       F2          F4
              Shift+Cmd+[ Shift+Cmd+] Ctrl+Cmd+F

```

## W -> Select

```text
              Shift+←       Shift+→
              Shift+Opt+←   Shift+Opt+→   Shift+Cmd+→
              Shift+Cmd+←
```

## E -> Move

```text
              ←       →
Cmd+←         Opt+←   Opt+→   Cmd+→
Enter         Enter
```

## R -> Delete

```text
              Backspace   Delete
Cmd+Backspace Opt+Backspace Opt+Delete Cmd+Delete

```

## A -> Nav

```text
              Tab   Tab
←             ↓     ↑     →
Enter         Enter Page Down Page Up
```

## S -> Punc

```text
              '   "   `
              ,   .   &
              ;   :   ~
```

## D -> Arith

```text
              <   >   #
              +   -   =
              *   /   %
```

## F -> Delim

```text
              {   }   !
              (   )   ?
              [   ]   $
```

## C -> More

```text
              ^
              |   @
              \   _
```

## V -> Num

```text
Backspace     7   8   9   +
.             4   5   6   -
0             1   2   3   Enter
```

## Left GUI -> Mouse

```text
Mouse Back        Middle Click        Mouse Forward
Mouse ←           Mouse ↓      Mouse ↑      Mouse →
Scroll ↓          Scroll ↑     Scroll ←     Scroll →
```

Thumbs:

```text
Left click Right click
```
